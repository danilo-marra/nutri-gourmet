# O que já parece possível integrar

1. MarketUp

O MarketUp possui recursos de integração com outros sistemas e marketplaces, o que indica que existe alguma forma de comunicação externa ou API disponível para parceiros. Porém, a documentação pública é limitada e provavelmente ele precisará solicitar acesso técnico ou verificar diretamente com o suporte do sistema.

2. Vlupt

A Vlupt se apresenta como uma plataforma completa para cantinas escolares, com controle de vendas, estoque, pagamentos, aplicativo para pais e até soluções White Label. Isso é um bom sinal porque sistemas desse tipo normalmente possuem alguma forma de integração ou exportação de dados. A própria Vlupt oferece customizações para empresas com múltiplas unidades.

3. Stone

Aqui a situação é mais simples. A Stone possui documentação aberta para desenvolvedores, APIs e webhooks. Isso significa que o sistema do seu cunhado consegue receber automaticamente a informação de que um pagamento foi realizado, sem precisar que alguém lance manualmente.
